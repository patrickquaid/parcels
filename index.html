About This Map

This interactive map shows the development of Roton Hill, an arbitrary area in South Norwalk. It's based on public parcel maps, with some edits and historical notes added.

The map is based on current data, so if a building's been replaced, it generally only knows about the new one. Also the underlying map, including the building outlines, is just the current map -- the slider has no affect on it.

If you see anything that ought to be changed, including especially any trivia or fun facts I should add, please let me know at rotonhill@rotonhill.com.

  • Timeline Slider: Drag the year slider or use − / + to step through time.
  • Parcels: Lots only appear once built or established, and split as historical subdivisions (or at least those that I know about) occur.
  • Details: Click on any parcel to see a little more information. If a parcel has a thicker outline, there is some historical trivia available.
